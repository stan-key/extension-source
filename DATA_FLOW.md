# Browser data flow

This inventory describes data read, sent and stored by the published browser
extension. Website analytics and campaign attribution are described on
[Stan's privacy page](https://stan-key.com/privacy). Machine-readable fields
are listed in [`security/data-contract.json`](./security/data-contract.json).

| Flow | Read in the browser | Sent by the extension | Extension storage | Browser-side purpose and retention |
| --- | --- | --- | --- | --- |
| Steam game comparison | Current Steam app/package identity, displayed price and currency, market and page language | App ID, Package ID, opaque market handle, displayed Steam price, currency and surface needed for the comparison request | No page contents are persisted. A short response cache expires after two minutes for positive results or 30 seconds for negative results. | Show a comparison for the Steam page the user opened. Request context is short-lived and is not written to extension local storage. |
| Wishlist comparison | Loaded wishlist rows and their app/package IDs and displayed final prices; the isolated script verifies the visible Steam row | The same bounded comparison context per eligible visible row | Short response cache only; wishlist contents are not written to extension storage | Show a comparison for the Steam wishlist row. The `MAIN` bridge emits six bounded fields and discards the surrounding Steam object. |
| Extension session | A random UUID v4 installation identifier generated by the extension | `{ "iid": "<random UUID v4>" }` to `POST /v2/extension/session`; later requests carry a short opaque session token in a header | The UUID is in extension local storage. The token is in `storage.session` when available, otherwise memory; it expires within six hours. | Support short-lived request continuity. The token is not an account credential and is not saved in local storage. |
| Installation measurement | A one-time first-run marker and random installation UUID | A random event ID and installation ID to the install-measurement path, then the same values in the first-party install page URL fragment | First-run marker and installation UUID remain in extension local storage | Measure extension installation. The extension does not keep a separate copy of the request after sending it. |
| Preferences | Merchant-category selections made in the extension UI | Not sent with comparison requests | `storage.sync` when available; falls back to `storage.local` if absent or unusable | Keep the user's display choices in browser extension storage until it is cleared or the extension is removed. Cross-device sync is browser-dependent and is not promised for Safari. |
| Offer action | The user selects an offer already shown by the extension | Browser navigation to the selected first-party Stan offer link | No offer or click history is stored by the extension | Open the offer selected by the user. The extension does not retain this navigation in browser extension storage. |

## Data not read by the extension

The browser packages do not request general browsing-history or cookie
permissions. The extension does not read Steam passwords, Steam access tokens,
checkout fields, payment details or unrelated form contents. It does not scan
pages outside the declared Steam content-script matches.

## Network metadata

Network requests include standard browser connection information. See
[Stan's privacy page](https://stan-key.com/privacy) for information about
network and service-provider processing.
